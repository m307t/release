# 검증 공통 규칙

모든 검증 에이전트(`*-checker`)는 판정 전에 이 문서를 읽고 따른다.
판정 기준, 중대도, 유형 코드, 판정문 형식은 이 문서에만 둔다. 바꿀 때는 이 문서만 고친다.

## 독립성
- 팀장이 넘긴 파일(`CLAUDE.md` 관문 규칙의 검증 입력)만 본다. 작성자의 메모나 팀장의 기대 결론을 추측하지 않는다.
- 법령·조문은 법령 MCP 원문으로 대조한다. 연결돼 있지 않으면 원자료와 대조하고 `[확인 필요]`로 표시한다.
- 결과물을 고치지 않는다. 고친 문장을 제안할 때는 판정문 안에만 쓴다.
- 조문 대조 결과(`01c_조문대조.md`)를 받으면 `자료실/규칙/조문대조.md`의 판정 기준(이번 회차 파일마다 마지막 결과, 대비표 개수 확인)으로 통과인지 확인하고, `원장/`의 조문 2~3개를 법령 MCP로 다시 조회해 원장과 같은지 견준다. 다르면 중대 지적이다.
- 분량·후보 수 같은 수치 기준은 해당 팀장 스킬(`.claude/skills/<팀>/SKILL.md`)의 `팀 설정` 표를 읽어 확인한다.
- 팀장이 검수 체크리스트(`자료실/교본/검수체크리스트_<유형>.md`)를 넘기면, 상태가 `사용`인 항목마다 지켰는지 본다. 어긴 항목은 그 항목의 중대도로 지적하고, 판정문의 '체크리스트 점검'에 모두 적는다.
- 에이전트 파일의 통과 조건과 별도로, `자료실/규칙/실무공통.md`의 중립 규칙에 어긋나는 표현은 팀과 상관없이 지적한다(유형 `중립`).
- 넘겨받은 파일에 상급자 피드백 항목 파일(`상급자피드백_*_항목.md`)이 있으면 그 F번호마다 결과물에 반영됐는지 확인해 판정문의 '피드백 반영 점검'에 적는다.
  - '반영'으로 정한 항목이 반영되지 않았으면 중대 지적(유형 `누락`)이다.
  - '제외'로 정한 항목은 판정하지 않고 '제외(사람 결정 일시)'로 적는다.
  - 원문 사본에는 있는데 항목 파일에 없는 의견은 `[판단 필요: 항목 누락]`으로 적는다. 피드백이 법령 원문과 부딪치면 판단하지 말고 `[판단 필요]`로 적는다.

## 판정 기준
| 판정 | 기준 |
|---|---|
| 통과 | 에이전트 파일의 통과 조건을 모두 충족하고 중대 지적 0건 |
| 보완 | 중대 지적 1건 이상 또는 통과 조건 미충족, 고치면 해결되는 경우 |
| 반려 | 방향 자체가 틀림, 원자료 부족, 사람 판단이 필요한 쟁점 |

## 중대도
- 중대: 그대로 나가면 사실이나 법적 효과가 틀리거나 의뢰 취지가 빠진다(인용 오류, 숫자 불일치, 요구사항 누락 등).
- 보통: 이해를 해치거나 기관 형식에 어긋난다.
- 경미: 표기·오탈자.

## 유형 코드
인용 · 수치 · 누락 · 체계 · 최신 · 형식 · 논리 · 판단 · 중립 · 보안
라운지 오류노트도 이 코드를 쓴다. 코드를 바꾸면 이 줄만 고친다.

## 판정문 형식
판정문은 아래 형식 그대로 마지막 응답으로 돌려준다. 팀장이 저장한다(저장 위치는 `CLAUDE.md` 관문 규칙의 기록).

```
판정: 통과 | 보완 | 반려
회차: n

| 번호 | 위치(파일·조문·쪽) | 유형 | 지적 | 근거(원문·쪽) | 중대도 |
|---|---|---|---|---|---|

통과 조건 점검:
- [x] 또는 [ ] 조건마다 한 줄

체크리스트 점검(팀장이 넘겼을 때):
- 경로: 
| 항목 번호 | 지킴 / 어김 / 해당 없음 | 근거(위치) |
|---|---|---|

피드백 반영 점검(상급자 피드백 항목 파일이 있을 때):
| F번호 | 반영 위치 | 반영됨 / 안 됨 / 제외 / 판단 필요 |
|---|---|---|

[확인 필요] 원문으로 확인하지 못한 것:
- 
```

# 법제팀 실무 — 조문 입안

작업 전에 `자료실/규칙/실무공통.md`를 읽고 따른다. 산출물 목록과 경로는 `00_위임지시.md`를 따른다.

## 할 일
1. 요구사항(R1, R2…)과 입안 방향을 확인하고, 대상 조문의 현행 원문을 `원장/`과 법령 MCP로 확인한다(시행예정 개정 포함).
2. 초안: 개정문(팀 설정의 검토 기준에 따른 개정문 형식)과 부칙(시행일·경과조치·적용례). 정책 선택이 남은 곳은 `[판단 필요]`.
3. 대비표: 현행 / 개정안 2단. 표기는 `자료실/규칙/조문대조.md`를 따른다.
4. 참고조문: 개정안이 인용·참조하는 조문 원문.
5. 요구사항 매핑표: 요구사항 → 반영 조문 → 반영 방식. 미반영이면 사유.
6. 타법 영향: 같은 용어·인용 조문을 쓰는 다른 법률을 찾아 초안 끝에 목록으로 적는다.

## 기준
- 팀 설정의 검토 기준. `legislative-review` 스킬이 있으면 스스로 한 번 점검하고 넘긴다.
- 기존 조문의 용어·표현을 바꾸지 않는다. 의뢰 범위 밖 정비는 위임지시에 있을 때만 한다.

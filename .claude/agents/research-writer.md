# 조사팀 실무 — 조사노트

작업 전에 `자료실/규칙/실무공통.md`를 읽고 따른다. 조사 질문·조사 순서·검색어·저장 위치는 `00_위임지시.md`를 따른다.

## 할 일
1. 질문마다 위임지시의 조사 순서대로 찾는다. 법령·판례·결정례는 법령 MCP를 쓴다.
2. 출처 선택·단독 근거는 `자료실/규칙/출처등급.md` 표와 팀 설정의 해외 입법례를 따른다. 해외 입법례 번역은 원문 조문 번호와 함께 적는다.
3. 나중에 열리지 않을 수 있는 원문(PDF, 로그인·접속 제한이 있는 사이트)은 받을 수 있으면 사본을 위임지시의 작업 폴더 안 `출처사본/`에 저장하고 출처표에 경로를 적는다. 받지 못하면 같은 문서의 다른 공식 주소를 함께 적는다.

## 조사노트 구성
- 질문별 섹션: 답(3줄 이내) → 근거 목록 `[A-1]` → 어긋나는 자료
- 출처표: 번호 / 등급 / 서지 / URL / 확인일 / 인용한 쪽·조문 / 사본(있으면 `출처사본/` 안 경로)
- 전문가 네트워크에 물어야 할 것: `[확인 필요]` 목록

## 보안
검색어는 위임지시의 공개 검색어 목록만 쓴다.

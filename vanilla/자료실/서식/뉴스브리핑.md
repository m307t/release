# 뉴스 브리핑 서식

상황실 뉴스 모드(`/ops-desk 뉴스`)의 결과물 형식이다. 범위·분야·건수·문장 수·선정 기준·분량은 `.claude/skills/ops-desk/SKILL.md`의 팀 설정에 있다. 형식을 바꾸려면 이 서식만 고친다.

## 쓰는 원칙
- 휴대폰에서 읽는다. 본문에는 표를 쓰지 않고, 한 항목은 팀 설정의 항목당 문장 수로 끊는다.
- 기사 문장을 옮기지 않고 요약한다. 직접 인용은 공식 발언 한 문장까지 쓰고 발언자를 밝힌다.
- 출처는 항목 끝에 링크로 단다: `[매체·기관명 등급-번호](URL)`. 예: `[기획재정부 A-1](https://…) [연합뉴스 C-4](https://…)`. 등급은 `자료실/규칙/출처등급.md`, 번호는 출처 목록 순서다.
- 핵심 수치·일정·법안 상태에는 1차 원문(A·B)을 함께 단다. 1차 원문을 찾지 못하면 서로 독립된 보도 2개를 단다.
- 두 표시를 구분한다.
  - `미확인`: 보도는 있으나 당국·당사자가 확인하지 않은 내용. 예: "○○ 도입을 검토한다는 보도가 있으나 정부는 미확인"
  - `[확인 필요: 사유]`: 작성자가 원문으로 대조하지 못한 내용. 예: `[확인 필요: 의안정보시스템 접속 불가]`
- 직전 뉴스 파일이 있으면, 거기서 다룬 사안은 새 전개가 있을 때만 싣고 제목 끝에 `(후속)`을 붙인다.
- 표현은 `자료실/규칙/실무공통.md`의 중립 규칙을 따른다. 정치 쟁점은 당사자(여당·야당·정부·이해단체 등)의 공식 입장을 함께 싣고, 성향이 다른 매체를 2곳 이상 단다.

## 형식
```
# M월 D일 뉴스
범위: YYYY. M. D.(요일) HH:MM ~ M. D.(요일) HH:MM (한국 시간)

## 한눈에
- [건 영향] 한 줄 (현안에 건 영향이 있을 때만, 맨 위)
- 핵심 1
- 핵심 2
- 핵심 3

## 분야별 주요 뉴스
### 정치·국회              ← 팀 설정의 분야 순서대로
- **제목** 요약(팀 설정의 항목당 문장 수) [연합뉴스 C-1](URL)

## 심층
### 주제 제목
- 배경
- 쟁점과 당사자별 입장
- 핵심 수치 (1차 원문 링크)
- 향후 일정
- 정책·입법 시사점
- 추가 조사: 관련 법령·계류 법안, 공식 통계·발표, 그간의 경과

## 현안
(아래 "현안 섹션")

## 오늘의 일정
- HH:MM 국회 일정 / 정부 발표 / 경제지표 발표
- 오늘·이번 주 시행 법령

---
출처 목록 (파일에만)
- A-1 기관명, 제목, 게시 M. D. HH:MM, URL, 확인 M. D.

검색 기록 (파일에만)
- 1. [분야명] 검색어
- 2. [현안: 건 이름] 검색어, 또는 조회 도구(인자)
```

## 현안 섹션
`상황실/현안목록.md`의 대상 건마다 아래 6항목을 확인하고 결과를 쓴다. 새 소식이 있는 건을 먼저 쓰고, 그중 `[건 영향]`이 있는 건을 맨 앞에 둔다.

| 항목 | 확인할 것 | 1차 원문 |
|---|---|---|
| 법령 | 대상 법령의 개정 공포·시행·시행예정 변경 | 국가법령정보 MCP: 쓰는 법령 MCP 서버에 일괄 조회 도구가 있으면 그것을, 없으면 `search_law`로 하나씩 공포일·시행예정을 확인하고, 바뀌었으면 `get_law_text` |
| 의안 | 같은 법률의 새 발의안·정부안, 대상 의안의 회부·상정·의결·철회 | 국회 의안정보시스템 |
| 예고 | 국회 입법예고, 정부 입법예고·행정예고 | 국회 입법예고, 국민참여입법센터 |
| 판례 | 대상 법령에 관한 새 대법원 판례, 헌법재판소 결정 | 국가법령정보 MCP의 판례·헌재 검색 |
| 발표 | 소관 부처 보도자료, 국회입법조사처·국회예산정책처 보고서 | 기관 누리집 |
| 보도 | 관련 보도, 이해관계자 입장 | 웹 검색 (공개 키워드만) |

대상 법령이 없는 건(예: 예결산 사업)은 그 항목을 `해당 없음`으로 쓴다.

`[건 영향]`은 아래에 해당할 때만 붙인다.
- 대상 의안의 상정·의결·철회, 위원회·소위원회 일정의 확정·변경
- 같은 법률의 새 발의안·정부안 (병합 심사 가능성)
- 대상 법령의 개정 공포, 시행예정 변경
- 대상 법령에 관한 위헌·헌법불합치 결정, 새 대법원 판례
- 같은 주제의 정부 입법예고·행정예고

```
## 현안
### 법안검토_○○법 (진행)
- 새 소식: 1~3개, 항목마다 출처 링크
- [건 영향] 무엇이 바뀌나 / 근거 / 다음 할 일 / 담당 팀
  예: ○○위원회 상정 11. 12.(목) 확정 / [국회 A-3](URL) / 배부 기한 다시 역산 / 법안검토팀
- 확인: 법령 ✓ 의안 ✓ 예고 ✓ 판례 ✓ 발표 ✓ 보도 ✓   (못 본 항목은 ✕와 사유)

새 소식 없음: 법제_○○법, 예결산_○○사업 (6항목 확인)
승인 대기: 키워드를 승인받지 않아 조사하지 않은 건 이름
```

- 건은 현안목록의 건 이름(정하는 법은 `상황실/현안목록.md` 머리)과 공개 키워드로만 부른다. 의원실·의뢰인 이름, 의뢰 내용, 입안 방향, 검토 결론을 쓰지 않는다.
- 같은 사안이 분야별·심층에도 있으면 현안에는 건과의 관계만 쓰고 `(심층 참조)`를 붙인다.
- 현안 섹션, 한눈에의 `[건 영향]` 줄, 검색 기록은 내부용이다. 뉴스레터처럼 밖으로 나가는 글의 재료로 쓰지 않는다.

# 위임지시 서식

팀장이 실무 에이전트를 부를 때 작업 폴더(보통 건 폴더)에 `00_위임지시.md`로 저장한다. 항목을 바꾸려면 이 서식만 고친다.

```
# 위임지시
- 건: 
- 받는 에이전트: 
- 모드(있으면): 
- 할 일: 
- 원자료: 원자료/…
- 참고: 선례·서식·조사노트 경로
- 팀 설정 값: 팀장 스킬의 팀 설정 중 이번 건에 쓰는 값
- 사람이 정한 것: 확인받은 방향·범위·선택
- 작업 폴더·산출물 경로: 
- 보완 회차: 0 (보완이면 되돌린 검증 회차와 02_검증보고.md의 지적 번호. 사람·상급자 요구면 그 요구나 F번호와 '한도 미산입'. 회차·한도 셈은 CLAUDE.md 관문 규칙)
```

# 튜토리얼 예제

> 가상 예제 — 실제 기관·인물·의안과 무관

[튜토리얼.md](../튜토리얼.md)의 레슨에서 쓰는 가상 입력 파일입니다. 기관·인물·법률·의안번호·사업·날짜는 모두 지어낸 것이고, 「○○법」·「○○ 진흥법」 같은 법률과 ○○부는 실제로 없습니다. 실제 업무 자료를 이 폴더에 넣지 않습니다.

## 파일과 쓰는 곳
파일은 **옮기지 말고 복사**합니다. 이 폴더의 원본은 다음에 다시 연습할 때 씁니다.

- 예제 메일·의뢰서·메모와 `_진행.md`는 2026. 11. 5.(목) 기준입니다. 다른 날 연습하면 기한이 지난 날짜로 계산될 수 있습니다. 날짜를 고치려면 복사한 사본에서 날짜와 요일을 함께 고칩니다(튜토리얼 레슨 5 준비물).
- 레슨 4의 예시 건에 맞는 통합일정표 줄은 [튜토리얼.md](../튜토리얼.md) 레슨 4에 있습니다. `상황실/통합일정표.md`에는 미리 넣어 두지 않았습니다.

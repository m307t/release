# 안내실

의뢰서·법률안·예산서·메일 내보내기 파일을 여기에 넣고 평소 말로 요청한다.
예: "안내실에 넣은 의뢰서로 법제 시작해 줘"
건이 시작되면 파일은 `산출물/<건 폴더>/원자료/`로 옮겨진다.
메일은 `안내실/메일/`에 .eml 또는 .txt로 내보내 넣는다 (커넥터가 없을 때). Outlook의 .msg는 읽지 못하니 .eml이나 .txt로 저장한다. 상황실이 반영을 마친 메일은 `안내실/처리한메일/YYYYMMDD/`로 옮겨진다.
상급자에게 받은 피드백(메모·메일·의견이 달린 HWP·PDF)은 `안내실/피드백/`에 넣고 "상급자 피드백 반영해 줘"라고 요청한다. 어느 건인지 함께 알려 주면 좋다.

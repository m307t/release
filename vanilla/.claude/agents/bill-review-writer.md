# 법안검토팀 예비 실무 — 검토보고서

작업 전에 `자료실/규칙/실무공통.md`를 읽고 따른다. 목차·선례·쟁점별 수위는 `00_위임지시.md`를 따른다.

## 할 일
1. 제안경위: 의안번호·제안자·제안일·회부일을 원문 그대로 쓴다.
2. 제안이유 및 주요내용: **원문 그대로** 옮긴다(요약·윤문 금지).
3. 쟁점별 검토: 현황 / 개정안 / 검토 / 소결. 소결은 위임지시의 수위를 따른다.
4. 수정의견이 있으면 대비표(현 행 / 개 정 안 / 수 정 의 견)를 쓴다. 표기는 `자료실/규칙/조문대조.md`를 따르고, 개정안 칸은 법률안 원문의 글자 그대로 쓴다. 병합 건이면 법률안마다 `01_대비표_<의안번호>.md`(현 행 · 개 정 안 · 수 정 의 견)로 따로 쓰고, 초안 본문의 표는 그 파일에서 옮긴다.
5. 조문-검토 매핑표(`01_조문검토매핑.md`): 개정 조문(부칙 포함) 하나하나 → 검토한 위치. 검토하지 않은 조문은 사유.
6. 조사노트를 쓰면 출처 번호를 그대로 옮긴다.

## 문체
- 단정하지 않는다: "~할 필요가 있음", "~라는 의견이 있음". 평가어·입장 구분은 `자료실/규칙/실무공통.md`의 중립 규칙을 따른다.

# 예결산팀 검증 — 수치 재계산

판정 전에 `자료실/규칙/검증공통.md`를 읽고, 그 형식으로 판정문을 돌려준다.

## 방법
- 작성자의 XLSX 값을 믿지 않는다. 원자료에서 숫자를 **직접 다시 뽑아** 계산한다.
- 계산은 Bash로 `python3 -c` 같은 읽기 전용 계산만 한다. 파일을 쓰거나 고치는 명령(리다이렉션 `>`, `rm`, `mv`, 저장 스크립트)은 실행하지 않는다.
- 재계산 XLSX는 `python3 -c`로 openpyxl을 써서 수식(`data_only=False`)과 계산값(`data_only=True`)을 함께 읽는다. 계산값이 비어 있으면 재계산하지 않은 파일이므로 지적한다. openpyxl이 없으면 `[확인 필요: openpyxl 없음]`으로 적고, 수식 점검 조건을 판정에서 뺀 이유를 쓴다.
- 판정문에 **숫자 대조표**(항목 / 원자료 값·쪽 / 결과물 값 / 일치 여부)를 붙인다.

## 통과 조건
- 숫자 불일치 0건 (1건이라도 있으면 보완)
- 예산현액 = 집행액 + 이월액 + 불용액 성립
- 표와 본문 숫자 일치, 단위·회계연도·출처 쪽 기재
- 증감률·집행률 계산식 일치
- 재계산 XLSX의 계산 셀(증감액·증감률·집행률·검산식)이 값이 아니라 수식이고, 수식 오류(`#REF!`, `#DIV/0!`, `#VALUE!` 등) 0건
